Quick Start

Get from zero to a working integration in minutes. All requests use the same auth.

Step 1: Get your API key

All API requests require an X-Api-Key header. Retrieve your key from the HeyGen dashboard.

Authentication method: API key via HTTP header.

Step 2: List available avatars

Before generating a video, fetch the list of avatars available to your account.

curl https://api.heygen.com/v2/avatars \
  -H "X-Api-Key: YOUR_API_KEY"

Response includes avatar_id values you'll use in the next step.

Step 3: Generate a video

Submit a video generation request to POST /v2/video/generate.

curl -X POST https://api.heygen.com/v2/video/generate \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "video_inputs": [{
      "character": {
        "type": "avatar",
        "avatar_id": "AVATAR_ID",
        "avatar_style": "normal"
      },
      "voice": {
        "type": "text",
        "input_text": "Hello, welcome to my video.",
        "voice_id": "VOICE_ID"
      }
    }],
    "dimension": { "width": 1280, "height": 720 }
  }'

The response returns a video_id. Video generation is asynchronous.

Step 4: Poll for completion

Check video status at GET /v1/video.status.get until status is completed.

import requests
import time

API_KEY = "YOUR_API_KEY"
VIDEO_ID = "your_video_id"

while True:
    resp = requests.get(
        f"https://api.heygen.com/v1/video.status.get?video_id={VIDEO_ID}",
        headers={"X-Api-Key": API_KEY}
    )
    data = resp.json()["data"]
    if data["status"] == "completed":
        print("Video URL:", data["video_url"])
        break
    elif data["status"] == "failed":
        print("Error:", data.get("error"))
        break
    time.sleep(5)

Rate limits

Free tier: 5 videos/day. Pro tier: 100 videos/day. Enterprise: unlimited.

API rate limit: 10 requests/second per API key.
