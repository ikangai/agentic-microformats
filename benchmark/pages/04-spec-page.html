llms.txt

A proposal for making website content accessible to large language models.

Home Proposal Python library docs llms.txt file

Overview

The llms.txt proposal suggests that websites add a /llms.txt file to their root directory. This file is written in Markdown and provides LLMs with background information and links to further documentation.

The file format is Markdown. It should be placed at the root of a website at the path /llms.txt.

Motivation

LLMs are increasingly being used to interact with websites and APIs. However, most websites are designed for human consumption and are not optimized for machine reading. The llms.txt proposal aims to bridge this gap.

Similar to robots.txt for web crawlers and sitemap.xml for search engines, llms.txt provides a standardized way for websites to communicate with AI systems.

File format

An llms.txt file must:

  • Be a Markdown file
  • Begin with an H1 title (the site/project name)
  • Optionally include a blockquote with a brief description
  • Include sections with H2 headings and bulleted link lists

Example

# My Project

> A brief description of what this project does.

## Docs
- [Getting started](https://example.com/start.md): How to get up and running
- [API reference](https://example.com/api.md): Full API documentation

## Optional
- [Changelog](https://example.com/changelog.md): Recent changes

Python library

A reference implementation is available as a Python library:

pip install llms-txt

See the full documentation for usage examples.
